# Bono Programable 1: Fundamentos de Combinatoria

Este repositorio contiene el desarrollo de dos ejercicios prácticos orientados a la implementación de algoritmos basados en conceptos fundamentales de combinatoria, utilizando Python como lenguaje base y Google Colab como entorno de ejecución interactivo.

---

## Estructura del Proyecto

El repositorio está organizado por módulos temáticos, cada uno con su propia lógica, cuaderno de trabajo y evidencias de ejecución.

* Ejercicio 1: Calculadora de factoriales, permutaciones y comparativa de eficiencia (iterativo vs. recursivo).
* Ejercicio 2: Sistema de conteo de contraseñas seguras basado en principios de inclusión-exclusión.

---

## Resumen de los Componentes

### Ejercicio 1: Calculadora de Factoriales y Permutaciones
Este módulo se centra en la resolución de problemas combinatorios clásicos y el análisis de rendimiento de algoritmos:
* Funcionalidad: Cálculo de $n!$ y $P(n, r)$ con validación estricta de entradas.
* Análisis de Rendimiento: Comparativa técnica entre enfoques iterativos y recursivos, midiendo tiempos de ejecución en microsegundos y observando el comportamiento de la pila de llamadas.

### Ejercicio 2: Sistema de Conteo de Contraseñas Seguras
Este módulo implementa un motor lógico para la generación y conteo de combinaciones bajo reglas específicas:
* Motor Combinatorio: Cálculo preciso con/sin repetición.
* Sistema de Restricciones: Aplicación del Principio de Inclusión-Exclusión para filtrar combinaciones que no cumplen con los requisitos mínimos.

---

## Instrucciones Generales

1. Acceso: Navega a la carpeta del ejercicio que deseas explorar.
2. Ejecución: Haz clic en el archivo .ipynb correspondiente.
3. Entorno: Utiliza el botón "Open in Colab" dentro de cada cuaderno para ejecutar el código de forma interactiva en la nube.
4. Interacción: Sigue las instrucciones de los menús desplegables en cada programa para realizar las pruebas.

---

## Validación de datos
Ambos ejercicios incluyen:
* Bloques `try-except`: Prevención de cierres inesperados ante entradas alfabéticas o inválidas.
* Validaciones numéricas: Verificación matemática previa a cualquier cálculo para asegurar que los parámetros sean correctos.
